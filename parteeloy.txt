#!/bin/sh
# Crea los usuarios del broker en cada arranque con las claves de raspberry/.env.
# Si falta alguna, el contenedor no arranca (mejor que arrancar con una clave por defecto).
set -e
: "${MQTT_NODERED_PASS:?Falta MQTT_NODERED_PASS: copia raspberry/.env.example como raspberry/.env}"
: "${MQTT_ESP32_PASS:?Falta MQTT_ESP32_PASS: copia raspberry/.env.example como raspberry/.env}"
PASSWORDFILE=/mosquitto/config/passwordfile
mosquitto_passwd -c -b "$PASSWORDFILE" nodealert "$MQTT_NODERED_PASS"
mosquitto_passwd -b "$PASSWORDFILE" nodealert_esp32 "$MQTT_ESP32_PASS"
chown 1883:1883 "$PASSWORDFILE"
chmod 0700 "$PASSWORDFILE"
echo "Usuarios del broker creados: 'nodealert' (Node-RED) y 'nodealert_esp32' (ESP32)"
chown -R 1883:1883 /mosquitto/data 2>/dev/null || true
exec "$@"

# Backend — Raspberry Pi (broker MQTT + Node-RED)
Recibe la telemetría del nodo ESP32 por MQTT, la guarda en SQLite y la expone por una API
REST que usa el dashboard (`frontend/`). También reenvía al nodo los comandos que se mandan
desde el dashboard.
```
ESP32 (o simulator.py) ──MQTT──► Mosquitto :1883 ──► Node-RED :1880 ──► SQLite (nodered.db)
        ▲                                               │
        └──────── nodealert/<id>/commands ◄─────────────┤ API REST /api/...
                                                        ▼
                                          frontend (nginx :3001)
```
## Servicios (`docker-compose.yml`)
| Servicio | Imagen | Puerto | Qué hace |
|---|---|---|---|
| `mosquitto` | `eclipse-mosquitto:2.0.20` | 1883 | Broker MQTT con usuario y clave obligatorios y ACL por usuario |
| `nodered` | `nodered/node-red:4.1.1` + `node-red-node-sqlite@2.0.1` | 1880 | Procesa la telemetría, base de datos y API REST |
| `frontend` | ver `frontend/README.md` | 3001 | Dashboard web |
## Contrato MQTT
| Tópico | Sentido | QoS | Formato |
|---|---|---|---|
| `nodealert/<device_id>/telemetry` | ESP32 → broker → Node-RED | 1 | JSON (abajo) |
| `nodealert/<device_id>/commands` | Node-RED → broker → ESP32 | 1 | texto plano |
Telemetría (cada 60 s y apenas cambia la presencia o el relé):
```json
{"device_id":"nodealert-luz01","presencia":1,"luz_ventana_lx":145.2,
 "luz_aula_lx":89.6,"temp_c":24.1,"humedad_pct":55.3,"rele_canal1":0}
```
| Campo | Tipo | Significado | Si el sensor falla |
|---|---|---|---|
| `device_id` | texto | Identificador del nodo | siempre está |
| `presencia` | 0/1 | 1 = sistema activo (hubo gente en los últimos 300 s) | se omite si el radar LD2420 no da datos |
| `luz_ventana_lx` | número | BH1750 de la ventana (lux) | se omite |
| `luz_aula_lx` | número | BH1750 del aula (lux) | se omite |
| `temp_c`, `humedad_pct` | número | SHT30 | se omiten los dos |
| `rele_canal1` | 0/1 | Estado del relé de las luces | siempre está |
Node-RED guarda los campos que faltan como `NULL` (nunca inventa un valor). Descarta (con un aviso en el log) los mensajes que no son JSON o cuyo
`device_id` no es válido.
Comandos aceptados: `RELE_ON`, `RELE_OFF` (pasan el nodo a modo manual), `AUTO` (vuelve al
modo automático), `REBOOT`, `LED_ON`, `LED_OFF`, `BUZZER_ON`, `BUZZER_OFF` (estos cuatro se
aceptan sin efecto en esta versión del hardware).
Usuarios del broker (permisos en `mqtt/aclfile`):
| Usuario | Lo usa | Puede |
|---|---|---|
| `nodealert` | Node-RED | leer `+/telemetry`, escribir `+/commands` |
| `nodealert_esp32` | firmware y `simulator.py` | escribir `+/telemetry`, leer `+/commands` |
## API REST (Node-RED, puerto 1880)
| Método | Endpoint | Respuesta |
|---|---|---|
| GET | `/api/health` | `{"status":"ok",...}` |
| GET | `/api/nodes` | Lista de nodos |
| POST | `/api/nodes` | Registra un nodo (`{"node_id","name"}`) |
| GET / DELETE | `/api/nodes/:node_id` | Ver / borrar un nodo |
| GET | `/api/telemetry/latest` | Última lectura de cada nodo |
| GET | `/api/telemetry/:node_id?limit=N` | Historial (N entero de 1 a 1000) |
| GET | `/api/telemetry/averages` | Promedios |
| POST | `/api/nodes/:node_id/command` | `{"command":"RELE_ON"}` → **202** y lo publica por MQTT |
| GET / POST | `/api/nodes/:node_id/config` | Configuración guardada en la base (el firmware no la lee) |
Validación: `node_id` tiene que ser letras, números, `-` o `_` (máximo 64); un comando fuera
de la lista o un `limit` inválido devuelven **400** con el motivo. Así no se pueden inyectar
consultas SQL ni publicar en tópicos arbitrarios.
## Cómo levantarlo
Requisitos: Docker Engine con Docker Compose v2.
```bash
cd raspberry
cp .env.example .env      # y cambiar las dos claves
docker compose up -d --build
```

## Probar sin hardware: `simulator.py`
Simula el nodo ESP32 con el mismo contrato que el firmware: mismo tópico, mismas claves JSON,
QoS 1, la misma regla de luz que `firmware/control-luz/main/regla_luz.h` (umbrales 60/100 lx,
debounce de 2 s, reposo tras 300 s sin gente), responde a los comandos y simula fallas de
sensores omitiendo los campos igual que el firmware.
Requiere Python 3.9 o superior.
```bash
cd raspberry
python3 -m venv .venv && . .venv/bin/activate     # Windows: .venv\Scripts\activate

export MQTT_ESP32_PASS=<la clave de .env>          # Windows: set MQTT_ESP32_PASS=...

```
Opciones útiles para una demo rápida:
```bash
python simulator.py --intervalo 5 --delay-off 20 --fail-rate 0.3 --ciclo-luz 60
```
| Opción | Default | Qué cambia |
|---|---|---|
| `--intervalo` | 60 | segundos entre publicaciones periódicas |
| `--delay-off` | 300 | segundos sin presencia hasta el reposo |
| `--fail-rate` | 0.05 | probabilidad de falla de cada sensor por lectura |
| `--prob-cambio-presencia` | 0.02 | probabilidad por segundo de que entre o salga alguien |
| `--ciclo-luz` | 600 | período del ciclo de luz natural simulado |
| `--device-id` | `nodealert-luz01` | id del nodo |
| `--duracion` | 0 (infinito) | segundos de simulación |
Prueba de punta a punta:
1. Con el simulador corriendo, `curl http://localhost:1880/api/telemetry/latest` muestra la

   `Comando recibido: RELE_ON` y la siguiente telemetría trae `"rele_canal1":1`.
3. Con `{"command":"AUTO"}` vuelve al modo automático.
4. Con `{"command":"CUALQUIERA"}` la API responde 400 y no publica nada.

        lect = {
            "radar_ok": random.random() >= a.fail_rate,
            "ventana_ok": random.random() >= a.fail_rate,
            "aula_ok": random.random() >= a.fail_rate,
            "sht_ok": random.random() >= a.fail_rate,
            "lux_ventana": round(max(0.0, lux_ventana), 1),
            "lux_aula": round(max(0.0, lux_aula), 1),
            "temp_c": round(24 + 2 * math.sin(2 * math.pi * t / 600) + random.uniform(-0.3, 0.3), 1),
            "humedad_pct": round(55 + 5 * math.sin(2 * math.pi * t / 900) + random.uniform(-1, 1), 1),
        }
        return lect
    # ---------- logica (igual que el loop del firmware) ----------
    def paso(self, lect):
        ahora = time.monotonic()
        if lect["radar_ok"] and self.persona:
            self.ultima_presencia = ahora
        activo_antes = self.sistema_activo
        self.sistema_activo = (ahora - self.ultima_presencia) <= self.args.delay_off
        if self.sistema_activo != activo_antes:
            self.publicar_ya = True
            print(">> Hay gente: sistema ACTIVO" if self.sistema_activo else ">> Sin gente: REPOSO")
        if self.manual:
            return
        deseado = regla_deseado(self.sistema_activo, lect["ventana_ok"], lect["lux_ventana"],
                                lect["aula_ok"], lect["lux_aula"], self.luz_encendida)
        if deseado == self.luz_encendida:
            self.candidato = deseado
        elif deseado != self.candidato:
            self.candidato = deseado
            self.desde_candidato = ahora
        elif ahora - self.desde_candidato >= DEBOUNCE_S:
            self.luz_encendida = deseado
            self.publicar_ya = True
            print(f">> RELE {'ON' if deseado else 'off'}")
    def armar_payload(self, lect):
        p = {"device_id": self.args.device_id}
        if lect["radar_ok"]:
            p["presencia"] = 1 if self.sistema_activo else 0
        if lect["ventana_ok"]:
            p["luz_ventana_lx"] = lect["lux_ventana"]
        if lect["aula_ok"]:
            p["luz_aula_lx"] = lect["lux_aula"]
        if lect["sht_ok"]:
            p["temp_c"] = lect["temp_c"]
            p["humedad_pct"] = lect["humedad_pct"]
        p["rele_canal1"] = 1 if self.luz_encendida else 0
        return p
    # ---------- comandos ----------
    def on_message(self, client, userdata, msg):
        cmd = msg.payload.decode("utf-8", errors="replace").strip()
        print(f"Comando recibido: {cmd}")
        if cmd == "REBOOT":
            print(">> Reinicio simulado")
            self.reiniciar_estado()
        elif cmd == "RELE_ON":
            self.manual, self.luz_encendida, self.publicar_ya = True, True, True
        elif cmd == "RELE_OFF":
            self.manual, self.luz_encendida, self.publicar_ya = True, False, True
        elif cmd == "AUTO":
            self.manual, self.publicar_ya = False, True
            print("Modo automatico reanudado")
        elif cmd in COMANDOS_SIN_EFECTO:
            pass
        else:
            print(f"Comando desconocido: {cmd}")
def main():
    ap = argparse.ArgumentParser(description="Simulador del nodo ESP32 control-luz")
    ap.add_argument("--broker", default="localhost")
    ap.add_argument("--port", type=int, default=1883)
    ap.add_argument("--user", default="nodealert_esp32")
    ap.add_argument("--password", default=os.environ.get("MQTT_ESP32_PASS"),
                    help="clave del usuario nodealert_esp32 (default: variable MQTT_ESP32_PASS)")
    ap.add_argument("--device-id", default="nodealert-luz01")
    ap.add_argument("--intervalo", type=float, default=60.0,
                    help="segundos entre publicaciones periodicas (firmware: 60)")
    ap.add_argument("--delay-off", type=float, default=300.0,
                    help="segundos sin presencia hasta el reposo (firmware: 300)")
    ap.add_argument("--fail-rate", type=float, default=0.05,
                    help="probabilidad de que cada sensor falle en una lectura (0 a 1)")
    ap.add_argument("--prob-cambio-presencia", type=float, default=0.02,
                    help="probabilidad por segundo de que entre o salga alguien")
    ap.add_argument("--ciclo-luz", type=float, default=600.0,
                    help="periodo en segundos del ciclo de luz natural simulado")
    ap.add_argument("--duracion", type=float, default=0, help="segundos de simulacion (0 = infinito)")
    args = ap.parse_args()
    if not args.password:
        sys.exit("Falta la clave: --password o variable MQTT_ESP32_PASS (ver raspberry/.env)")
    nodo = NodoSimulado(args)
    client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2, client_id=f"sim-{args.device_id}")
    client.username_pw_set(args.user, args.password)
    client.reconnect_delay_set(min_delay=1, max_delay=30)   # backoff como un cliente real
    def on_connect(c, userdata, flags, reason_code, properties):
        if reason_code.is_failure:
            print(f"Conexion rechazada por el broker: {reason_code}")
            return
        print(f"Conectado a {args.broker}:{args.port}; escuchando {nodo.topic_cmd}")
        c.subscribe(nodo.topic_cmd, qos=1)
        nodo.publicar_ya = True
    client.on_connect = on_connect
    client.on_message = nodo.on_message
    client.connect_async(args.broker, args.port, keepalive=60)
    client.loop_start()
    fin = time.monotonic() + args.duracion if args.duracion > 0 else None
    try:
        while fin is None or time.monotonic() < fin:
            lect = nodo.leer_sensores()
            nodo.paso(lect)
            vencio = time.monotonic() - nodo.ultima_publicacion >= args.intervalo
            if client.is_connected() and (nodo.publicar_ya or vencio):
                payload = nodo.armar_payload(lect)
                client.publish(nodo.topic_tel, json.dumps(payload, separators=(",", ":")), qos=1, retain=False)
                print(f"-> {nodo.topic_tel} {payload}")
                nodo.ultima_publicacion = time.monotonic()
                nodo.publicar_ya = False
            time.sleep(1.0)
    except KeyboardInterrupt:
        pass
    finally:
        client.loop_stop()
        client.disconnect()
if __name__ == "__main__":
    main()
