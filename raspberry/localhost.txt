Todo en tu máquina local (localhost / 127.0.0.1):
Servicio	Puerto	URL
MQTT Broker	1883	localhost:1883
Node-RED editor	1880	http://localhost:1880 (http://localhost:1880)
Frontend React	3001	http://localhost:3001 (http://localhost:3001)
IP local de tu PC (la que necesitan los ESP32 para conectarse al broker MQTT):
ip addr show | grep "inet " | grep -v 127.0.0.1
Esa IP reemplazala en el firmware donde dice 192.168.0.195. Por ejemplo, si la IP es 192.168.1.100, el ESP32 se conecta a 192.168.1.100:1883.



1. Instalar Docker en la RPi (si no está):
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker pi
# cerrar sesión y volver a entrar, o ejecutar: newgrp docker
2. Instalar Docker Compose plugin:
sudo apt install -y docker-compose-plugin
3. Clonar el proyecto y copiar la carpeta:
# Si tenés el proyecto en otra máquina, copialo:
scp -r /home/sebastian/Escritorio/nodered pi@raspberrypi:~/
# O cloná si está en Git:
# git clone <url> nodered && cd nodered
4. Ajustar la IP del broker en Node-RED (porque la RPi es su propia IP):
# La IP de la RPi es la IP del broker. Verificá cuál es:
ip addr show | grep "inet " | grep -v 127.0.0.1
Esa IP va en el firmware de los ESP32 como servidor MQTT.
5. Solo si cambiás la IP del broker (no hace falta si Node-RED y Mosquitto corren en la misma RPi, porque usan localhost internamente). El docker-compose usa redes internas, no necesita IP — los contenedores se ven por nombre de servicio (mosquitto, nodered, frontend).
6. Levantar todo:
cd nodered
docker compose up -d --build
7. Verificar:
docker compose ps
curl http://localhost:1880/api/health
curl http://localhost:3001
Los ESP32 se conectan a mosquitto_puerto:1883 apuntando a la IP de la RPi.
